# Sample books

Public-domain EPUBs from Project Gutenberg, used by the sample library until the real mirror
exists (spec 002, research R2). Project Gutenberg texts are public domain in the US; each file
keeps its Project Gutenberg licence text as distributed.

| File | Source |
|---|---|
| `george-eliot_middlemarch.epub` | Project Gutenberg #145, from the official mirror gutenberg.pglaf.org |
| `herman-melville_moby-dick.epub` | Project Gutenberg #2701, from the official mirror gutenberg.pglaf.org |
| `bram-stoker_dracula.epub` | Project Gutenberg edition, copied from the owner's machine |
| `robert-w-chambers_the-king-in-yellow.epub` | Project Gutenberg edition, copied from the owner's machine |
| `john-milton_paradise-lost.epub` | Project Gutenberg edition, copied from the owner's machine |

The sample covers are Standard Ebooks covers of the same works, so the edition shown on the
cover differs from the text inside. Anna Karenina and Meditations have no sample file: opening
them shows the "not on this device" state.

Standard Ebooks' robots.txt asks AI agents not to fetch their downloads or text pages, so no
Standard Ebooks file is fetched automatically.
